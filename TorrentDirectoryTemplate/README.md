# Torrent Directory Template

A dark, responsive torrent-directory style UI template inspired by classic index layouts.

This template is for lawful content only: public-domain, Creative Commons, open-source, Linux distributions, and other content you are authorized to distribute.

## Layout

- Dark background with pink accent styling
- Large search bar
- Category navigation
- Popular/trending table
- Name, seeders, leechers, date, size, and uploader columns
- Mobile-friendly responsive layout
- Detail-page-ready card structure

The design deliberately does not connect to unauthorized copyrighted torrent indexes or provide piracy links.
